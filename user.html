Authorized User Portal

ส่วนผู้ใช้งาน

พื้นที่สำหรับผู้ปฏิบัติงานที่ได้รับสิทธิ์ ใช้ยืนยันตัวตนก่อนเริ่มงาน โดยระบบจะจำกัดข้อมูลตามบทบาทและพื้นที่รับผิดชอบ

เข้าสู่ระบบ

ใช้รหัสผู้ใช้และ PIN ที่แอดมินกำหนด ระบบจะไม่รับรหัสผ่านผ่าน URL และจะจำ session เฉพาะในเครื่องนี้ชั่วคราว

เปิดระบบแผนที่

เข้าสู่ระบบด้วยรหัสผู้ใช้ + PIN
อย่าแชร์ PIN หรือถ่ายภาพหน้าจอที่มีตำแหน่งบ้านเลขที่

หลักการใช้งาน

  1. 1

    ใช้เพื่อภารกิจที่ได้รับมอบหมาย

    เข้าถึงเฉพาะข้อมูลที่จำเป็นต่อหน้าที่ของตนเอง

  2. 2

    ไม่ส่งต่อข้อมูล

    ห้ามคัดลอกหรือเผยแพร่ข้อมูลพื้นที่นอกวัตถุประสงค์ของงาน

  3. 3

    แจ้งเหตุผิดปกติ

    หากเข้าไม่ได้หรือพบข้อมูลผิดพลาด ให้แจ้งผู้ดูแลระบบทันที
