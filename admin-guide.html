อยู่ในระหว่างทดสอบระบบ

Administrator Guide

คู่มือผู้ดูแลระบบ

แนวทางปฏิบัติเพื่อกำกับการใช้งานอย่างปลอดภัยและตรวจสอบได้

  1. 1

    ตรวจสอบบัญชีผู้ขอใช้

    ยืนยันตัวบุคคล วัตถุประสงค์ และบทบาทก่อนกำหนดสิทธิ์ ไม่ใช้รหัสผ่านหรือ PIN ร่วมกัน

  2. 2

    กำหนดสิทธิ์แบบน้อยที่สุด

    ให้เข้าถึงเฉพาะพื้นที่และฟังก์ชันที่จำเป็นต่อหน้าที่ และทบทวนสิทธิ์เมื่อมีการเปลี่ยนงาน

  3. 3

    ติดตามและตอบสนอง

    ตรวจบันทึกการเข้าถึง ระงับบัญชีทันทีเมื่อไม่จำเป็น และบันทึกเหตุผลการดำเนินการ

  4. 4

    ก่อนเปิดใช้จริง

    ทดสอบการปฏิเสธ token ปลอม บัญชีไม่อยู่ใน allowlist บัญชีถูกระงับ และการเรียก API โดยตรง

เปิดหน้าแอดมินคู่มือผู้ใช้
คู่มือฉบับทดสอบ · ปรับปรุงก่อนเปิดใช้ข้อมูลจริง
