# ระบบข้อมูลพื้นที่ชุมชน

หน้าเว็บสำหรับผู้ประสานงานพื้นที่ ใช้รหัสผู้ใช้ + PIN ที่แอดมินกำหนด และไม่เก็บข้อมูลพิกัด, PIN หรือข้อมูลประชาชนไว้ใน GitHub

## สถานะ

หน้า GitHub Pages เป็นเพียงหน้าจอเข้าสู่ระบบและแผนที่ ข้อมูลจะมาจาก Apps Script หลังจาก server ตรวจ session, สถานะผู้ใช้ และพื้นที่รับผิดชอบแล้วเท่านั้น

ก่อนเปิดรับข้อมูลจริง ต้องทำให้ครบ:

1. ใน Google Sheet เลือกเมนู “กำหนดรหัสผ่านแอดมินครั้งแรก” แล้วตั้งรหัสผ่านยาวอย่างน้อย 12 ตัวอักษร
2. เข้า `/exec?page=admin` เพื่อกำหนดรหัสผู้ใช้, PIN, บทบาท และพื้นที่รับผิดชอบ
3. ทดสอบบัญชีที่อนุญาต, PIN ผิด, บัญชีที่ถูกระงับ และผู้ใช้ต่างพื้นที่ รวมถึงการเรียก endpoint โดยตรง
4. ก่อนนำข้อมูลจริงเข้า ให้ผู้รับผิดชอบข้อมูลทบทวนวัตถุประสงค์, ระยะเวลาเก็บ, สิทธิ์ผู้ใช้ และแนวทางรับเหตุข้อมูลรั่วไหล

ห้ามใส่ API key, token, PIN, รหัสผ่าน หรือข้อมูลพื้นที่จริงใน repository นี้
